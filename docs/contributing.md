# Contribution

## Règles obligatoires

- Modifier uniquement le skill concerné.
- Conserver les mots complets et les références auto-explicatives.
- Ne pas déplacer une ressource vers un dossier partagé sans usage commun démontré.
- Ne pas supprimer une partie issue des documents sources sans décision explicite.
- Mettre à jour le manifeste de conservation lorsqu’une partie préservée est déplacée.
- Ajouter ou adapter les scénarios lorsque le comportement normatif change.
- Maintenir le guide d’installation et le prompt de démarrage du skill lorsque ses exigences ou ses garde-fous évoluent.
- Exécuter le validateur avant toute proposition de fusion.

## Validation attendue

    python scripts/validate-all-skills.py

Une contribution n’est prête que lorsque la structure, les liens, les frontmatters et les empreintes de conservation sont valides.
